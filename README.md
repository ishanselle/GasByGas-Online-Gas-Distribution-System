# GasByGas Online Gas Distribution System

## 📦 Project Overview

GasByGas is a web-based gas distribution system designed for **GasByGas (Pvt) Ltd.** It automates gas order processing, customer management, distributor assignment, and real-time delivery tracking. This project was built using agile methodologies and adheres to **ISO/IEC 12207:2008** standards and **IEEE** project planning frameworks.

## ✅ Key Features

- Online gas booking and tracking
- Admin and distributor dashboards
- Customer account management
- Order assignment and status updates
- Responsive front-end UI
- Real-time system notifications
- Secure login with role-based access
